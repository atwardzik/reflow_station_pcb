# Reflow Station

This project is currently in a prototype stage. It features PCB project of
basic reflow station utilizing 4 phase-controlled triacs steering with attached
heaters. The temperature is controlled by the STM32F469VIT6 MCU with attached
ADS1118 thermocouple interfaces.
